OpenAI key

          
The key for the chosen model's provider; the field follows the model. It goes to the console service with the run request, stays in that run's process for its duration, and is never written to the service's logs or disk. This browser keeps it in session storage until the tab closes. The service has no key of its own.

Stage moves, approach, scans, gate ramps and sweeps wait for the operator; analysis tools run on their own.

        
        
Ticked, a navigation run gets only the objective and the fixed parameters, and the backend gives the agent two skills that describe how the two main uncertainties of navigation show in the data (an interrupted scan after the tip retracts, an uncertain position estimate) and what the remedies are; the agent decides when to read them. Unticked, it gets the team's prompt with those rules written in as steps 3 and 7, as in the paper's runs.
